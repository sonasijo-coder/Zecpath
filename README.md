# Django Clean Architecture Project

A production-ready Django backend built with modular project structure, environment configuration, and clean code practices.

## 🚀 Features
- **Clean Architecture:** Separated `apps/`, services, utils, and core modules.
- **Environment Handling:** Secure `.env` setup for API keys and debug settings.
- **Clean Imports & Refactoring:** Modular code following PEP 8 naming conventions.

## 🛠️ Tech Stack
- **Backend:** Python, Django
- **Version Control:** Git, GitHub
